Keep your data safe

  1. Schedule backup_now.bat daily with Windows Task Scheduler (steps are in the README).
  2. Copy backups off the server: set a second copy folder in System settings, pointing at an external drive or a synced cloud folder.
  3. Test a restore regularly. With HIMS stopped, run flask --app run verify-backup <file> to check a backup, or flask --app run restore <file> to restore it.
